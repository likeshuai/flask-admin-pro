# Flask Admin Pro - 产品设计文档

## 1. 产品概述

### 1.1 产品定位
Flask Admin Pro 是一个可嵌入 Flask 项目的后台管理系统 Python 库，通过 `pip install` 即可集成，零前端构建成本。

### 1.2 目标用户
- Flask 开发者
- 需要快速搭建后台管理系统的团队
- 希望最小化部署复杂度的个人开发者

### 1.3 核心价值
- 🔌 **即插即用** - 一行代码集成到现有 Flask 项目
- 📦 **零构建** - 无需 Node.js，无需 npm，无需打包
- 🎨 **开箱即用** - Element Plus + Vue 3，现代化 UI
- 🔒 **安全可靠** - 内置认证、权限、日志

## 2. 功能架构

### 2.1 核心模块

```
┌─────────────────────────────────────────────────────┐
│                  Flask Admin Pro                     │
├─────────────┬─────────────┬─────────────┬───────────┤
│   认证模块   │   用户管理   │   模型管理   │  监控模块  │

```

### 2.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 后端框架 | Flask 2.x | 轻量级 Python Web 框架 |
| 前端框架 | Vue 3 + Element Plus | 通过 CDN 引入 |
| 模板引擎 | Jinja2 | Flask 内置 |
| ORM 适配 | SQLAlchemy / Peewee | 双 ORM 支持 |
| 数据库 | SQLite / MySQL / PostgreSQL | 灵活配置 |

## 4. 部署架构

### 4.1 集成方式

```python
from flask import Flask
from flask_admin_pro import AdminPro

app = Flask(__name__)
admin = AdminPro(app, database_uri='sqlite:///admin.db')
```

### 4.2 访问路径
- 管理后台：`http://localhost:5000/__admin__/`
- API 接口：`http://localhost:5000/__admin__/api/`
- 静态资源：`http://localhost:5000/__admin__/static/`

### 4.3 默认凭据
- 用户名：`admin`
- 密码：`admin123`

---

## 5. 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `DATABASE_URI` | str | `sqlite:///admin.db` | 数据库连接 |
| `SECRET_KEY` | str | 自动生成 | Flask 密钥 |
| `ADMIN_USERNAME` | str | `admin` | 默认管理员 |
| `ADMIN_PASSWORD` | str | `admin123` | 默认密码 |
| `THEME_COLOR` | str | `blue` | 主题色 |
| `ENABLE_MONITOR` | bool | `True` | 启用监控 |

## 6. 非功能性需求

### 6.1 性能
- 页面加载时间 < 2s
- API 响应时间 < 500ms
- 支持 100+ 并发请求

### 6.2 安全
- 密码 bcrypt 加密
- CSRF 保护
- SQL 注入防护
- XSS 防护

### 6.3 兼容性
- Python 3.8+
- Flask 2.0+
- 现代浏览器（Chrome/Firefox/Safari/Edge）
