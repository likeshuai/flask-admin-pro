## 2. 开发任务清单

### 2.1 核心层 (core/)

| 文件 | 功能 | 优先级 |
|------|------|--------|
| `extensions.py` | 初始化 db, login_manager | P0 |
| `models.py` | AdminUser, RequestLog 模型 | P0 |
| `auth.py` | 登录、登出、权限验证 | P0 |
| `crud.py` | 通用 CRUD 操作 | P0 |
| `orm_adapter.py` | SQLAlchemy/Peewee 适配 | P1 |
| `monitor.py` | 请求统计、日志记录 | P1 |

### 2.2 路由层 (admin.py)

| 路由 | 方法 | 功能 | 优先级 |
|------|------|------|--------|
| `/__admin__/` | GET | 仪表盘/重定向到登录 | P0 |
| `/__admin__/login` | GET/POST | 登录页 | P0 |
| `/__admin__/logout` | POST | 登出 | P0 |
| `/__admin__/api/login` | POST | 登录 API | P0 |
| `/__admin__/api/users` | GET/POST | 用户列表/创建 | P0 |
| `/__admin__/api/users/<id>` | PUT/DELETE | 用户更新/删除 | P0 |
| `/__admin__/api/models` | GET | 模型列表 | P0 |
| `/__admin__/api/models/<name>` | GET/POST | 模型数据查询/创建 | P0 |
| `/__admin__/api/models/<name>/<id>` | PUT/DELETE | 模型数据更新/删除 | P0 |
| `/__admin__/api/monitor/stats` | GET | 监控统计 | P1 |
| `/__admin__/api/monitor/logs` | GET | 请求日志 | P1 |

## 3. 数据模型设计

### 3.1 AdminUser (管理员用户)

```python
class AdminUser(db.Model):
    __tablename__ = 'admin_users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password_hash = db.Column(db.String(255), nullable=False)
    email = db.Column(db.String(120))
    role = db.Column(db.String(20), default='admin')  # admin, operator
    is_active = db.Column(db.Boolean, default=True)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    updated_at = db.Column(db.DateTime, onupdate=datetime.utcnow)
```

### 3.2 RequestLog (请求日志)

```python
class RequestLog(db.Model):
    __tablename__ = 'request_logs'
    
    id = db.Column(db.Integer, primary_key=True)
    method = db.Column(db.String(10))
    path = db.Column(db.String(255))
    status_code = db.Column(db.Integer)
    response_time = db.Column(db.Float)  # ms
    ip_address = db.Column(db.String(45))
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
```

## 4. API 接口设计

### 4.1 认证接口

```
POST /__admin__/api/login
Body: { "username": "admin", "password": "admin123" }
Response: { "success": true, "user": { "id": 1, "username": "admin" } }

POST /__admin__/api/logout
Response: { "success": true }
```

### 4.2 用户接口

```
GET /__admin__/api/users?page=1&per_page=20
Response: { "users": [...], "total": 10, "page": 1, "pages": 1 }

POST /__admin__/api/users
Body: { "username": "new", "password": "123", "email": "...", "role": "admin" }

PUT /__admin__/api/users/<id>
Body: { "username": "...", "email": "...", "role": "...", "is_active": true }

DELETE /__admin__/api/users/<id>
```

### 4.3 模型接口

```
GET /__admin__/api/models
Response: { "models": ["User", "Post", "Comment"] }

GET /__admin__/api/models/User?page=1&per_page=20&search=xxx
Response: { "data": [...], "total": 100, "columns": [...] }

POST /__admin__/api/models/User
Body: { "field1": "value1", "field2": "value2" }

PUT /__admin__/api/models/User/<id>
Body: { "field1": "new_value" }

DELETE /__admin__/api/models/User/<id>
```

### 4.4 监控接口

```
GET /__admin__/api/monitor/stats?range=24h
Response: { "requests": [...], "errors": [...], "avg_response_time": 123 }

GET /__admin__/api/monitor/logs?page=1&limit=50
Response: { "logs": [...], "total": 1000 }
```
